# Експерименти: конструктор і запуск

## Статуси експерименту

- `creating` — створення (дефолтний стан).
- `configuring` — користувач почав налаштування (оновлення графа або налаштувань).
- `computing` — запущені обчислення.
- `completed` — немає активних запусків (усі виконані/зупинені/з помилкою).

## Правила конструктора

- Порядок етапів фіксований: попередня обробка → підсилення даних → видобуток ознак →
  зменшення розмірності → класифікація.
- Додавання вузла дозволяє лише наступні етапи після батьківського.
- Редагування вузла не дозволяє змінити етап на попередній, якщо існує батьківський етап.
- Для етапу класифікації не показується кнопка додавання дочірнього вузла.

## Налаштування графа

- Метрики `accuracy`, `f1`, `rocAuc`, `ntps` зберігаються в діапазоні 0..1.
- У UI ваги вводяться у відсотках (0-100), сума має дорівнювати 100% (тобто 1 у даних).
- Типи обчислень — мультивибір (локально/хмара). Без вибору запуск заборонений.

## Запуск обчислень (ExperimentDetailsPage)

- Карточка **"Шляхи класифікації"** відображає таблицю шляхів і дій (запуск/зупинка/перезапуск).
- Колір графа відображає статус шляху:
  - `queued` — синій
  - `running` — жовтий
  - `failed` — червоний
  - `completed` — зелений
  - `stopped` — рожевий
  - `idle` — світло-сірий (немає запусків)
- Обчислення заборонені, якщо хоча б один шлях не містить етап класифікації.
- Кнопка `info` відкриває модал з деталями останнього запуску шляху.

## PDF звіт

- Кнопка "Завантажити PDF" зʼявляється лише у статусі `completed`.
- REST URL для завантаження: `{API_BASE}/experiments/:id/report`, де `API_BASE` — GraphQL URL без `/graphql`.

## Блокування редагування

- Після старту обчислень (статуси `computing`/`completed`) редагування експерименту, налаштувань графа і етапів графа вимкнено.
