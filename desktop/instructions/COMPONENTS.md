# Довідка: додавання компонентів у десктопному застосунку

## Структура

- `src/pages/*` — тільки оголошення сторінок і збір готових компонентів.
- `src/components/` — усі повторно використовувані компоненти:
  - `common/` — дрібні універсальні елементи (кнопки, теги, повідомлення).
  - `inputs/` — поля введення, комбобокси, валідовані контролли.
  - `layout/` — обгортки, гріди, контейнери, панелі.
  - `auth/` — сутності автентифікації (форми логіну/реєстрації тощо).
  - за потреби додавай інші сутності (`billing/`, `profile/`), але сторюй їх у `components/`.

## Кроки, щоб додати новий компонент

1. Вибери папку за призначенням (наприклад, інпут у `inputs/`, форма в `auth/`).
2. Створи компонент у своїй папці. Якщо потрібен повторний експорт, додай `index.ts`.
3. Якщо є специфічні стилі, поклади їх поруч (`Component.module.css`/`Component.css`).
4. Використовуй у сторінках лише готові компоненти, без бізнес-логіки прямо в `pages`.
5. Для форм на Formik/Yup тримай схеми поруч із компонентом, а обробку успіху передавай через пропси.

## Таблиці

- У таблицях дії в рядках оформлюй як іконки без тексту (але з `aria-label`/`title` для доступності).

## Типи

- Не використовуй `as` для примусового приведення типів — краще тип-гарди або уточнення типів.

## Приклад

- Поточні форми логіну/реєстрації знаходяться в `src/components/auth/LoginForm.tsx` та `src/components/auth/RegisterForm.tsx`.
- Сторінка `src/pages/public/WelcomePage.tsx` лише підключає ці форми та робить навігацію/колбек успіху.
